# Aspik — Rizal Hidayat Putra

Personal portfolio V1 for **aspik.dev**.

> From raw code to pure vision.

## Stack
- Next.js 14 + TypeScript
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Custom responsive CSS

## Run locally
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## V1 direction
The interaction language is inspired by high-energy editorial/motorsport portfolios: oversized typography, full-viewport imagery, split identities, cinematic project reveals, smooth motion and high contrast. The design, branding, content and visual system are original to Aspik.
