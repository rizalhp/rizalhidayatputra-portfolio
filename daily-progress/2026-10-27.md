## Local link-fragment regression coverage

Added a regression test in `tests/test_check_local_links.py` for two browser-compatible local fragment forms:

- A percent-encoded fragment that resolves to an existing element ID.
- A text-fragment directive (`:~:text=`) appended to an element fragment, which should not be treated as part of the element ID.

The test asserts that both local links are counted and produce no audit errors. This change is limited to the Python validation tests and progress documentation; no portfolio HTML, styles, scripts, or visual assets were changed.
