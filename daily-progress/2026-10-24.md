# Daily Progress — 24 October 2026

## Vercel header configuration regression tests

Added `tests/test_vercel_config.py` to parse the checked-in `vercel.json` and protect its deployment-header contract:

- Validate the structure of header rules and reject duplicate route sources or duplicate header names within a rule.
- Keep the configured cache policy scoped to `/assets/(.*)`, rather than the catch-all route.
- Preserve the current `X-Content-Type-Options`, `Referrer-Policy`, and `Permissions-Policy` values on the catch-all route.

The existing GitHub Actions workflow discovers this file through `python3 -m unittest discover -s tests`. These tests check repository configuration; they do not claim to inspect live HTTP responses or verify a production deployment.
